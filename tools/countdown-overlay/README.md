# 카운트다운 오버레이

발표 중 파워포인트 슬라이드쇼나 전체 화면 브라우저 위에 남은 시간을 작게 띄우는 macOS 앱이다.

- 분류: Prototype (발표, 워크숍 진행용 개인 도구)
- 위치: 설치본 `~/Applications/카운트다운.app`, 바탕화면 바로가기 `~/Desktop/카운트다운`

## 사용법

1. 바탕화면의 `카운트다운`을 더블클릭한다.
2. 시간 설정 창이 `03:00`으로 뜬다. `−`/`+` 버튼이나 ↑↓ 키로 1분씩 조정하고 `Start`(또는 Enter)를 누른다. `1분`~`15분` 버튼은 값만 바꾼다. `2:30`처럼 직접 적어도 된다.
3. 오른쪽 위에 반투명 시계가 뜬다. 다른 앱을 전체 화면으로 띄워도 시계는 위에 남는다.
4. 0이 되면 빨간 `00:00`으로 세 번 깜빡이고 멈춘다. 남은 30초부터는 숫자가 노란색이 된다.

시계 조작
- 마우스를 올리면 오른쪽 위에 X가 뜬다. 누르면 종료한다.
- 드래그: 위치 이동 (다음 실행 때도 그 자리에 뜬다)
- 우클릭: 일시정지/계속, 처음부터 다시, 시간 다시 설정, 종료

실행할 때마다 기본값은 `03:00`이다. 시계 위치는 기억한다.

## 다시 빌드하기

```bash
./build.sh
```

`main.swift`를 컴파일해 `~/Applications`에 설치하고 바탕화면 별칭을 새로 만든다. Xcode Command Line Tools(`swiftc`)만 있으면 된다.

## 파일

| 파일 | 역할 |
|---|---|
| `main.swift` | 앱 전체 (설정 창, 오버레이 시계, 우클릭 메뉴) |
| `make-icon.swift` | 앱 아이콘 PNG 생성 |
| `build.sh` | 빌드, 서명, 설치, 바탕화면 바로가기 |

## 알려진 한계

- 소리는 내지 않는다. 발표 중 알림음이 방해될 수 있어서 시각 신호만 둔다.
- 바탕화면 바로가기는 빌드할 때마다 지우고 하나만 새로 만든다. 한글 파일명의 NFC/NFD 표기가 달라 예전 별칭이 남는 문제를 막으려고 정규화해서 지운다.
- 바탕화면(iCloud 동기화 폴더)에서 직접 서명하면 확장 속성 때문에 실패한다. 그래서 `build.sh`는 `~/Applications` 설치본에 서명한다.
