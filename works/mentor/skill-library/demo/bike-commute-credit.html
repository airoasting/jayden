스크리닝 결과

엑셀에 적은 라이딩 날짜마다 인증 게시글이 있어야 일치로 봅니다.

추출 비율 0.25(구분별, 최소 1명), 시드 20261025, 판정 기준은 날짜별 게시글 1개 이상입니다. 불일치는 담당자가 게시글을 직접 확인해 확정한 뒤 정산에 반영했습니다.

직접 실행해 보기

저장소 README의 세 줄입니다. 샘플 데이터도 가상입니다.

설치, 샘플 생성, 정산

# 1. 의존성 설치 (openpyxl 하나)
py -m pip install openpyxl
# 2. 가상 샘플 엑셀 만들기
py tests/make_sample.py sample/sample.xlsx
# 3. 3분기 정산
py .claude/skills/bike-commute-credit/scripts/cc.py settle \
   --workbook sample/sample.xlsx --quarter 3 --as-of 2026-10-25

이 화면은 3번 명령에 --roster(입·퇴사 명단)와 --screening(확정된 스크리닝 결과)을 더한 경우를 가정했습니다. macOS와 Linux는 py 대신 python3를 씁니다. 설치 없이 쓰려면 web/index.html을 브라우저로 열고 같은 엑셀을 올리면 됩니다.
