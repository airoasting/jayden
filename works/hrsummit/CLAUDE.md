## 3. 색

로고 그린과 바탕은 사용자가 준 로고 이미지의 픽셀 표본이다(공식 가이드 아님). 공식 값을 받으면 `#3add2e`, `#1f9a14`, `rgba(58,221,46,…)`를 일괄 치환한다.

| 이름 | 값 | 쓰는 곳 |
|---|---|---|
| 서밋 그린 | `#3ADD2E` | 막대, 면, 점, 그래프 |
| 그린 글자 | `#1F9A14` | 흰 바탕 위 강조 글자 |
| 서밋 바탕 | `#111911` | 표지·마무리 로고 배지 |
| 코랄 | `#FF7878` | 보조 강조, 두 번째 계열(올리브영판에서 물려받음) |
| 잉크 | `#1A1A1A` | 기본 글자, 그린·코랄 면 위 글자 |
| 회색 | `#6F7880`, `#98A1A8` | 보조 글자, 주석 |

- 바탕은 모든 장 흰색, 그라디언트 없음. 진하게 칠한 면은 장마다 하나, 나머지는 옅은 색(`#F7F8F9`, `#EFFCEE`, `#FFE6E6`).
- 그린 면 위 글자는 잉크로 쓴다.

## 4. 문구

- 헤드라인 어미는 `~함`, `~중`, `~것임` 같은 명사형으로 통일한다.
- 한 문장 안의 주어와 서술어를 맞춘다. `-고`로 이은 두 동작은 주체가 같아야 한다.
- 정본에 없는 숫자, 사례, 인용을 만들지 않는다.
- 사실(~함·발표함), 계획(~예정·목표), 전망(~할 전망·가능성이 큼), 제안(~해야 함)을 어미로 구분한다. "그리다" 같은 비유 대신 "고려·계획"처럼 객관적으로 쓴다.

1. 저장소 루트의 `.claude/launch.json`에서 `static` 서버(포트 8791)를 띄운다.
