# 출력 예시

사용자가 제공한 예시. 한 회의 transcript 중 **AI 파트만** 발췌해 작성한 것이다. 톤(개조식), 불릿 밀도, `[소속]` 태그, 들여쓰기 방식을 참고한다.
이 예시의 2-1처럼 해당 아젠다에서 확정된 의사결정이 없으면 의사결정사항 섹션을 생략한다. 제목만 있는 아젠다(예: "1. Traackr API")는 논의가 짧아 발췌에서 비워둔 경우이며, 실제 작성 시에는 내용을 채운다.

```
261014 Weekly Call 회의록 - AI 파트

1. Traackr API

2. 신규 Agent 개발

2-1. Performance Analyst

논의사항

* [커니] 챗봇은 기존 계획상 12월 초 개발계, 내년 1월 운영계 배포 목표. Rule-based Summary의 AI 전환 및 추가 질의응답 기능 포함 예정.
   * [삼성전자] AI 기능의 11~12월 내 도입 필요성 제기. 챗봇 개발 일정 재공유 및 조기 적용 가능 여부 검토 요청.
   * [커니] 챗봇 UI는 MAP 공통 컴포넌트에 맞춰 변경 예정. 삼성전자 측 추가 준비사항은 현재 없음.

Next Step

* [커니] 챗봇 개발·배포 일정 재검토 후 삼성전자에 공유. 11~12월 도입 가능성 확인.
* [커니] MAP 공통 챗봇 UI 예시 및 마전 측 기존 챗봇 배포 일정 확인 후 공유.


2-2. Recruiter

논의사항

* [삼성전자] 로그인 및 외부 파트너 계정 사용 방식 확인.
   * [커니] 이메일 기반 가입 방식 검토 중이나, 삼성전자 보안 요건에 따른 최종 결정 필요.

Next Step

* [커니] 업데이트된 Recruiter 접속 정보 공유.


2-3. Brief Curator

논의사항

* [커니] 기존 장문 텍스트를 축약하고, 인플루언서·유사 유형의 고성과 콘텐츠 레퍼런스를 포함하는 방향. 스토리보드 이미지 생성은 별도 테스트 예정.
* [삼성전자] 형식보다 가이드의 실용성과 새로운 아이디어 제안이 중요. 기존 고성과 포맷 반복이나 AI가 작성한 티가 나는 답변은 지양 필요.
* [삼성전자] 인플루언서 개인의 Organic 콘텐츠/Tone & Manner, 경쟁사·이종 브랜드 사례 등 입력 데이터 확대 요청.
   * [커니] 현재 Insight Lens는 글로벌 Team Galaxy 콘텐츠 기반이며, 개인화에는 Bio Scraper 및 최근 채널별 6~9개 게시물(Organic 포함), 캠페인 Direction 등을 활용 중.
   * [삼성전자] 캠페인 Direction이 매우 간략하게 입력되는 실제 사용 상황도 고려 필요.

Next Step

* [커니] 실제 인플루언서 사례 기반으로 브리프 품질 검증 및 참신성·실행 가능성 개선.
* [커니] Organic·Co.A·이종 브랜드·트렌딩 콘텐츠 등 분석 입력 범위 확대 방안 검토.
* [커니] 최소한의 캠페인 Direction 입력 시나리오 포함해 테스트 진행.
```

## 참고: 의사결정사항이 있는 경우의 모양

같은 회의의 다른 아젠다(일정 협의)를 이 형식으로 쓰면 다음과 같다. 사용자가 준 예시에는 없으므로 형식 참고용이다.

```
3. 연말 전략 고도화 일정

논의사항

* [커니] 트래커 대체 솔루션 32개 롱리스트 검토 중. 솔루션사 회신 지연으로 11월 중 전달 가능 여부 문의.
* [삼성전자] 대체 솔루션 검토 시 데이터 수급 자동화·지원 수준도 평가 기준에 반영 요청.

의사결정사항

* 트래커 대체 솔루션 검토 결과는 11월 중 전달.
* 전체 고도화 Deck은 11월 20일 이전 배포 목표로 진행.

Next Step

* [커니] 대체 솔루션 평가 항목에 데이터 파이프라인 협조도·용이성 추가.
* [삼성전자] 절대값/비율 기준 KPI 타겟 방향 내부 논의 후 공유.
```
