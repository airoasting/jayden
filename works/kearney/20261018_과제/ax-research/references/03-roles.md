# Black / Red 역할과 실행 방식

| 역할 | 책임과 검토 관점 |
|---|---|
| Black — 리서치 작성자 | 조사·작성·수정·통합을 담당한다. 리뷰 지적에 근거를 갖춰 응답하며 자신의 점수는 평균에 포함하지 않는다. |
| Red 1 — 근거 감사자 | 주장과 원문 일치, 출처 추적, 사실·해석·가정·합성 구분을 검토한다. |
| Red 2 — 분석 방법 검토자 | 계산·집계, 비교 정의와 범위, 누락값 처리, 대안 해석을 검토한다. 정성 자료도 비교 논리가 타당한지 확인한다. |
| Red 3 — 의사결정 검토자 | 사용자 질문에 대한 답, 시사점의 근거와 적용 가능성, 빠진 판단 요소를 검토한다. |
| Red 4…n — 추가 전문 검토자 | 과제에 필요한 산업·운영 등 별도의 전문 관점을 맡는다. 추가 이유를 명시한다. |

## 구성

- 기본 구성은 Black 1명과 Red 3명이다.
- 첫 평가 전에 다음을 정하고 `results/` 실행 폴더의 `run-config.md`(저장하는 경우) 또는 대화에 기록한다: 담당 관점, 채점 기준, 목표 9.5/10, 최대 라운드 수, 실제 검토 방식.

## 실행 방식

1. **별도 Subagent 호출이 가능할 때.** 각 Red를 분리해 실행한다. 병렬 실행이 어려우면 순차 호출한다. 이 폴더의 `templates/reviewer-brief.md`에 역할 지침과 채점표를 채워 전달하며, 미리 설치된 에이전트 이름이나 설정을 전제하지 않는다.
2. **호출이 불가능하거나 권한·역할상 허용되지 않을 때.** 같은 Agent가 Red 관점을 차례로 적용하고 **동일 Agent의 페르소나별 자기 검토**라고 밝힌다. 실제로 호출하지 않은 리뷰어를 독립 Agent로 보고하지 않는다.

## 독립성 규칙

- 실제 별도 리뷰에서는 동일한 초안, 사용자 요구, 원자료, 채점표를 전달한다.
- 각 Red는 다른 리뷰어의 점수·의견을 보기 전에 평가한다.
- 수정은 Black만 담당한다. Red는 초안을 직접 수정하지 않고 지적과 점수를 반환한다.
- Red는 리뷰어를 추가 생성하거나 이 전체 루프를 재귀적으로 실행하지 않는다.
