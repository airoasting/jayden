# 공통 채점표

모든 Red가 아래 다섯 항목을 각각 **0~2점, 0.1점 단위**로 평가한다. 항목 합계가 리뷰어별 10점 만점 점수이며 리뷰어 간 가중치는 동일하다.

첫 평가 전에 요청 범위에 맞는 확인 사항을 정한다. 정량 분석이나 벤치마킹을 요청하지 않았다면 그 기능의 부재로 감점하지 말고 실제 수행한 정성 분석의 논리와 범위를 평가한다.

| 항목 | 평가 기준 |
|---|---|
| 정확성과 구분 | 주장·계산이 확인한 내용과 일치하고 사실·해석·가정·합성이 구분되는가? |
| 출처 추적성 | 주요 주장에서 출처와 실제 원문 위치를 재확인할 수 있는가? |
| 분석·비교 타당성 | 계산·집계 또는 정성 비교의 정의·논리·적용 범위가 타당한가? |
| 의사결정 유용성 | 사용자 질문에 답하고 시사점의 근거·적용 조건·대안 해석을 제시하는가? |
| 완결성과 한계 | 요청 범위와 형식을 충족하며 미확인 항목·한계·후속 질문이 명확한가? |

## 항목별 점수 기준

| 점수 | 의미 |
|---|---|
| 0 | 누락 또는 근본 오류 |
| 1 | 중요한 보완 필요 |
| 1.5 | 핵심을 충족했으나 실질적 수정 필요 |
| 1.9 | 실질적 결함 없이 경미한 개선만 남음 |
| 2 | 확인한 범위에서 기준 충족 |

중간 점수에도 구체적인 이유를 붙인다.

## 리뷰어 반환 항목

- 검토한 버전
- 항목별 점수와 근거, 합계
- 지적 사항: 위치 또는 근거 ID, 심각도, 확인한 근거, 필요한 수정
- 지적이 없어도 확인한 내용과 채점 근거를 남긴다.

양식: `templates/review-report.md`

## 심각도

| 심각도 | 정의 |
|---|---|
| **차단** | 가공 출처, 필수 주장의 근거 부재, 결론을 바꾸는 계산 오류 등 |
| **중대** | 비교·사용자 판단에 영향을 주는 오류나 누락 |
| **경미** | 결론이나 재현성에 영향을 주지 않는 표현·형식 개선 |

## 주의

- 읽지 않은 출처나 수행하지 않은 계산을 검증 완료로 채점하지 않는다.
- 점수는 품질 판단이며 사실의 정확성을 보증하는 확률이 아니다.
