# 비교 축

3단계(비교 축 설계)에서 읽는다.

## 기본 5개 축 — 모든 벤치마킹에 둔다

| 축 | 담는 내용 |
|---|---|
| 개요·추진 배경 | 언제, 왜, 어떤 계기로 시작했는가 |
| 전략·포지셔닝 | 무엇을 목표로, 어떤 위치를 잡았는가 |
| 핵심 제공물 | 제품·서비스·프로그램의 실제 내용 |
| 운영 방식·조직·재원 | 누가, 어떤 조직과 돈으로 운영하는가 |
| 성과 지표 | 공개된 수치와 그 정의·시점 |

## 분야별 추가 비교 축 — 힘찬이 질문에 필요한 것만 고른다

| 분야 | 추가 비교 축 |
|---|---|
| 기업·제품 | 가격·수익 모델, 고객 세그먼트, 기술·차별화 요소, 유통 채널 |
| 서비스·운영 | 서비스 프로세스, 고객 접점, 품질 관리 체계, 디지털 전환 수준 |
| 공공정책 | 법·제도 근거, 예산·재원 구조, 거버넌스·추진 주체, 정책 대상·성과 |
| 교육·연구기관 | 조직 체계, 교육·연구 프로그램, 대외 협력, 평가·인증 성과 |
| 도시·인프라 | 도입 규모·투자비, 기술 사양, 운영 주체·모델, 이용 실적·만족도 |

- 해당 분야가 표에 없으면 힘찬이 같은 형식으로 3~4개 축을 새로 제안한다.
- 축 이름은 질문 맥락에 맞게 다듬어도 된다(예: 사내 서비스면 "고객 접점" → "이용자 접점"). 다듬었으면 원래 축 이름을 내부 기록에 남긴다.
- 질문과 관련이 약한 축은 넣지 않는다. 축이 많다고 좋은 매트릭스가 아니다(권장 총 6~8개).
- 성과 지표 행은 대상마다 지표 종류(접근 인원, 채택률, 매출 등)가 다를 수 있다. 셀 안에 지표 종류를 굵게 먼저 쓴다.
