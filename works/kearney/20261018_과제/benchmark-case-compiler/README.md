# benchmark-case-compiler

둘 이상의 대상(기업, 제품·서비스, 정책, 기관, 도시 등)을 **같은 기준으로 비교하는 벤치마킹**을 수행하는 Claude 스킬입니다.
다섯 페르소나가 조사·검토·채점을 나눠 맡고, 검증(6개 영역 모두 9.5점 이상)을 통과한 **비교 매트릭스 HTML 한 장**을 결과로 냅니다.

- 출처는 **공신력 있는 자료**(공식 발표·공시·정부 보고서·주요 언론·전문지)만 씁니다.
- 실행일 기준 **최근 24개월 이내에 발행된 자료**만 씁니다. 채울 수 없는 칸은 "미확인"으로 둡니다.
- 결과 HTML은 그레인 텍스처 스타일에 페이퍼로지 글꼴을 쓰고, 셀마다 출처 링크가 달립니다.

## 구성

```
benchmark-case-compiler/
├─ SKILL.md              # 스킬 본문 (페르소나 · 평가 기준 · 맥락 · 도구 · 진행 규칙/출력 형식 · 하지 말 것)
├─ references/
│  ├─ axes.md            # 기본 5개 비교 축 + 분야별 추가 축
│  ├─ personas.md        # 페르소나별 산출물·검토 순서·보완 루프
│  └─ rubric.md          # 채점 규칙 · 검증 절차 · 중단 조건
├─ assets/
│  └─ template.html      # 비교 매트릭스 HTML 템플릿
└─ examples/
   └─ benchmark-genai-enterprise-adoption-2026-10-17.html   # 실행 결과 예시
```

## 설치

Claude Code 개인 스킬 폴더에 복제합니다.

```bash
git clone https://github.com/er2d/bm.git ~/.claude/skills/benchmark-case-compiler
```

프로젝트 단위로 쓰려면 프로젝트의 `.claude/skills/` 아래에 복제합니다.

## 사용 예

> 국내외 대기업의 생성형 AI 사내 도입 사례 4곳 벤치마킹해줘

"벤치마킹", "사례 비교", "국내외 사례 조사", "경쟁사 비교표" 같은 표현을 쓰면 스킬이 자동으로 호출됩니다.

## 페르소나

| 이름 | 역할 |
|---|---|
| 알렉스 | 조사 담당자 — 자료 수집, 매트릭스 작성, 통합 (자기 채점 금지) |
| 힘찬 | 전문가 — 비교 축 적정성, 용어·해석 정확성 |
| 르네 | 비판적 의사결정자 — 가장 약한 근거 3가지, 비교 한계 |
| 마벨 | 동조자 — 근거 있는 강점 옹호 |
| 쫄랑 | 고객 — 최종 이용자의 체감 가치·불편·수용성 |
