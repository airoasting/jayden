# 변경 로그 템플릿

아래 형식을 그대로 사용한다.

```markdown
# 강의자료 최신화 변경 로그

- 원본: [원본 파일명]
- 수정본: [수정본 파일명]
- 작업일: YYYY-MM-DD
- 강의 핵심 메시지: [1단계에서 정리한 한 단락 요약]

## 진단 요약
전체 N장 중 유지 N장 / 보완 N장 / 교체 N장 / 검토 필요 N장 / 진단 제외 N장.
[가장 중요한 변경 2~3가지를 한두 문장으로]

## 슬라이드별 변경 내역
| 슬라이드 | 등급 | 진단 기준 | 기존 내용 | 변경 내용 | 출처 |
|---|---|---|---|---|---|
| 5 | 보완 | 통계 연도 | 2019년 조사 수치 | 최신 조사 수치로 교체 | 기관, 연도, 제목 |

## 확인 필요 항목
검색으로 확인하지 못했거나 강사의 판단이 필요한 항목. 슬라이드 번호, 내용, 사유를 적는다.

## 추가 제안
슬라이드에 직접 넣지 않은 아이디어: 새 모듈, 새 실습, 최신 트렌드를 다룬 추가 슬라이드 구성안 등.
```
