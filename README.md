## Day 1 수업이 추가된 복사본

- **모션 켜짐/꺼짐**, 전체 화면, 기존 페이지의 인터랙션을 지원합니다.

## Career Atlas (지도 위 경력 여정)

`jaydenkang_20261005.html`은 경력 7개 지점을 3D 지도 위에서 차례로 날아가며 보여주는 단독 페이지입니다. 경영 리더 대상 AI 워크샵 첫머리에 강사 소개로 프로젝터에 띄우는 용도입니다. 슬라이드 덱과 별개 파일이며, 다른 HTML은 건드리지 않았습니다.

- 순서: 프리챌(선릉역 삼성생명 대치타워), 커니, 미시간 MBA, 베인, 라인 태국, 카카오엔터테인먼트(판교), 라이너.
- 자동 재생은 약 77초입니다. 지점마다 4초(2마디) 머물고, 결론인 라이너는 8초(4마디) 머물며 카메라가 밀고 들어가고 3번째 마디에 배경 K-AI FRONTIER가 뜹니다.
- **음악:** 재생 버튼을 누르면 120 BPM 오리지널 비트가 함께 시작합니다. 외부 음원이 아니라 Web Audio로 직접 연주하므로 저작권 문제가 없고 파일 하나로 동작합니다. 장면 전환은 박에, 전환 화면은 마디 첫 박에 맞춰 시작하고(실측 오차 약 0.05초), 시대 전환에는 임팩트, COVID-19 카드에는 먹먹해지는 효과, 출장 도시마다 8분음표 블립이 들어갑니다. 일시 정지하면 음악도 멈추고, `M` 키나 ♪ 버튼으로 소리를 끕니다.
- 전환 화면: INTERNET ERA(프리챌 앞), MOBILE ERA(미시간 유학 앞), AI ERA(라이너 앞)는 세 줄이 위아래 반대 방향으로 흐르는 형식이고, COVID-19 OUTBREAK(방콕에서 판교로 오기 전)는 테두리 상자 한 줄의 사건 카드로 구분합니다.
- 카카오엔터테인먼트에서는 출장 화면(PANGYO → LOS ANGELES, NEW YORK, BANGKOK, TAIPEI, JAKARTA)을 보여줍니다. 원이 퍼지며 열리고, 도시 이름은 색 박스가 지나가며 드러납니다.
- 요약 화면: 3 ERAS / 8 CITIES / 5 COUNTRIES, GLOBAL EXPERIENCE. K-AI FRONTIER. 지구가 천천히 돌며 지나온 도시와 출장 도시를 점으로 보여줍니다(선은 긋지 않습니다).
- 지도 글자는 도착한 뒤에만, 한국 지점은 한국어로, 해외 지점은 영어로 흐리게 나옵니다.
- `Space` 재생/일시 정지, `←` `→` 지점 이동, 숫자 `1`–`7`로 해당 지점 바로 가기, `R` 처음부터, `F` 전체 화면, `M` 소리 끄기/켜기.
- **인터넷 연결이 필요합니다.** 지도 타일(OpenFreeMap), 지도 엔진(MapLibre), 애니메이션(GSAP), 글꼴을 외부에서 불러옵니다. 지도를 못 불러오면 격자 배경으로 끝까지 진행하고 요약 화면도 나옵니다(지도 엔진을 막고 검증함).

### 품질 기준과 평가 기록

5-Color Harness 비평가 4명(RED 논리, SILVER 연출, BLUE 감정, GOLD 50대 임원 청중)으로 7차례 채점했습니다. 종합 평균은 1차 6.4에서 7차 8.8로 올랐고, RED는 9.5로 합격 판정했습니다. BLUE와 GOLD(8점대)가 남긴 격차는 소유자 결정(역할·연도 미표기, 출장 화면 크기, COVID 화면 유지)이 정한 상한으로 보고, 재생 직후 강사의 첫 문장으로 메우기로 했습니다. 장면 캡처와 채점 브리프는 `.build/eval/`에 있습니다.

### 고칠 때

- 지점 데이터는 파일 안 `const STOPS` 배열 하나에 모여 있습니다. `dwell`(체류), `dwellAfter`(출장 화면 뒤 체류), `fly`(비행 시간), `opens`(이 지점 앞에서 새 시대 전환), `before`(사건 카드), `trips`(출장 화면), `climax`(결론 연출), `tagFull`(태그 전체 문구) 필드로 조정합니다.
- 기본 시간은 `DWELL`, `FLY` 상수이고, 주석에 70초 예산 계산식이 있습니다. 30초와 90초는 정신없었고, 대양 횡단을 4.5초로 줄이면 지도 타일이 덜 그려진 채 보였습니다.
- 흐르는 줄 안쪽 요소의 클래스는 `mtrack`입니다. `track`은 하단 레일 선 이름이라, 겹치면 전환 화면 글자가 1px로 눌립니다.
- 로고는 모두 어두운 패널에 맞춘 흰색 또는 원색 이미지로 HTML에 들어 있습니다. 라이너 로고는 받은 이미지의 흰 배경을 투명하게 바꾼 흰색 PNG입니다(`.build/liner-logo-white.png`).
- 음악은 `const Music` 한 곳에 있습니다. 템포는 `BPM`, 코드 진행은 `CH`·`ROOT`, 악기 패턴은 `play()`에서 바꿉니다. 시간 상수를 바꿀 때는 박(500ms)의 배수를 유지해야 장면이 박에 떨어집니다.
- 검증 스크립트(`.build/`, Git 제외): `beat-run.mjs`(박자 정렬 측정), `full-run.mjs`(전체 재생 타임라인), `eval-all.mjs`(장면 15장 캡처), `check-climax.mjs`(라이너·요약), `nomap-run.mjs`(지도 엔진 없이 재생).

## 슬라이드

1. **자기소개 질문**: 이름과 하는 일, AI 활용, 유료 구독, 업무 적용, 워크샵 기대에 관한 다섯 가지 질문. 질문 카드를 누르면 크게 볼 수 있습니다.
2. **강정구 소개**: 경력 타임라인, 학력, 자문 활동. 회사와 시대를 선택해 살펴볼 수 있습니다.

## 사용 방법

`index.html`을 다운로드한 뒤 웹 브라우저에서 엽니다. 별도 설치나 빌드가 필요하지 않습니다.

- 상단 탭 또는 `Page Up` / `Page Down`으로 페이지를 이동합니다.
- **전체 화면** 버튼 또는 `F` 키로 전체 화면을 전환합니다.
- 경력 소개 페이지의 **자동 재생** 버튼으로 타임라인을 재생합니다.
- 질문 확대 화면에서는 좌우 화살표로 질문을 바꾸고 `Esc`로 닫습니다.
